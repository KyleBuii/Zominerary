# [Zominerary](https://zominerary.vercel.app/)
Call of Duty zombies easter egg helper.

The main focus of the helper is to encourage exploring and figuring out things yourself. It tells you what to do, but some steps are vague. Images are provided to assist navigation.

This is for people who prefer a written guide and likes the ideas presented above.

## Available Guides
### Black Ops 7
- Ashes of the Damned
- Astra Malorum
